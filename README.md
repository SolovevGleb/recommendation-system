## Система рекомендаций

Проект представляет собой полноценную рекомендательную систему, включающую обучение ML-моделей, расчет персональных рекомендаций и сервис инференса.

Для применения модели в реальном сценарии был разработан API-сервис на FastAPI. Сервис получает идентификатор пользователя (`user_id`) и время запроса, обращается к базе данных PostgreSQL, формирует необходимые признаки и рассчитывает персональную выдачу.

Логика работы системы:
- пользователь отправляет запрос с `user_id` и временем обращения;
- система загружает пользовательские и контентные признаки из базы данных;
- генерируются временные признаки активности пользователя;
- модель оценивает вероятность взаимодействия пользователя с постами;
- формируется персональный список рекомендаций Top-K.

Таким образом, система реализует полный цикл работы рекомендательного сервиса: от подготовки признаков и инференса ML-модели до выдачи персональных рекомендаций через API.

## Описание проекта

В работе использовались данные взаимодействий пользователей с постами, признаки пользователей, признаки постов и текстовые признаки, полученные с помощью TF-IDF. Всего было обработано более 3 млн взаимодействий.

В рамках проекта выполнен полный цикл разработки ML-решения:
- анализ и подготовка данных;
- feature engineering;
- обучение моделей;
- сравнение качества моделей;
- оценка итоговых рекомендаций.

## Feature Engineering

Были реализованы:
- генерация временных признаков активности пользователей;
- циклическое кодирование временных признаков через sin/cos;
- создание текстовых признаков постов с использованием TF-IDF;
- подготовка пользовательских и контентных признаков.

## Модели

Были обучены и сравнены следующие модели:

- Logistic Regression — baseline-модель;
- CatBoostClassifier;
- LightGBM;
- RecMLP Neural Network на PyTorch.

Результаты:

| Model | HitRate@5 |
|-------|-----------|
| LightGBM | 0.6852 |
| CatBoost | 0.6813 |
| RecMLP | 0.6719 |
| Logistic Regression | 0.6082 |

Лучший результат показала модель **LightGBM** с HitRate@5 = **0.6852**.  
Градиентный бустинг на деревьях превзошел как baseline Logistic Regression, так и нейронную сеть RecMLP.

## Оценка качества

Для оценки использовалась метрика **HitRate@5**.

Метрика показывает, попал ли хотя бы один релевантный пост пользователя в топ-5 рекомендаций модели.

Для корректной оценки использовалось временное разбиение данных (**time split**):
- 70% данных — обучение;
- 30% данных — тестирование.

Также был реализован единый evaluation pipeline для расчета HitRate@5 и сравнения различных моделей.

## A/B тестирование моделей

В рамках развития рекомендательной системы была реализована версия сервиса с поддержкой A/B тестирования моделей.

Пользователи распределяются между экспериментальными группами **test** и **control** на основе детерминированного хеширования `user_id` с использованием MD5 и фиксированной соли.

В зависимости от группы пользователя сервис использует разные версии рекомендательных моделей:
- **Control группа** — baseline модель;
- **Test группа** — новая версия модели.

Такой подход позволяет проводить контролируемое сравнение качества моделей и оценивать эффективность новых алгоритмов перед внедрением.

**Примечание:** код реализации A/B тестирования не включен в текущий репозиторий и приведен только как пример возможного расширения рекомендательного сервиса.
